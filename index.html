❓ FAQ

Common questions about BZAT.ai.

What is BZAT.ai?

BZAT.ai is an AI-powered content creation platform designed to help creators turn ideas into publishable content.

Can I create images?

Yes. BZAT.ai includes an AI Image Creator that lets users generate images from text prompts. Image generation does not use BZAT.ai creator credits.

Can I upload an image?

Yes. You can select an image and preview it inside BZAT.ai.

Is BZAT.ai free?

BZAT.ai includes free content creation features. AI image generation is available without BZAT.ai creator credits. Paid credit plans are available for additional creator usage.

Are API keys exposed in the website?

No. BZAT.ai uses server-side Workers for API communication. Secret API keys are stored as Cloudflare Worker secrets rather than being placed directly inside the website code.
